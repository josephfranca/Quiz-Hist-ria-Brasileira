# 🇧🇷 Quiz: História do Brasil

Um aplicativo de quiz interativo com interface gráfica desenvolvido em Python utilizando a biblioteca **Tkinter**. O projeto testa os conhecimentos do usuário sobre momentos marcantes da história do Brasil, desde o descobrimento até o movimento das Diretas Já.

##  Funcionalidades

* **Interface Gráfica Amigável:** Visual limpo e responsivo construído inteiramente com Tkinter.
* **Feedback em Tempo Real:** Caixas de mensagem (`messagebox`) indicam se o usuário acertou ou errou, exibindo a resposta correta em caso de erro.
* **Sistema de Pontuação:** O placar é atualizado dinamicamente na tela a cada resposta.
* **Fechamento Automatizado:** Ao responder a última pergunta, o app exibe o score final e encerra a janela com segurança.


## Tecnologias Utilizadas

* **Python 3.x**
* **Tkinter** (Biblioteca padrão do Python para interfaces gráficas)



##  Perguntas Incluídas

O quiz conta com questões sobre os seguintes temas:
1. A chegada de Pedro Álvares Cabral (1500).
2. A Proclamação da Independência (1822).
3. O primeiro presidente do Brasil (Deodoro da Fonseca).
4. O início da Ditadura Militar (1964).
5. O lema "50 anos em 5" de Juscelino Kubitschek.
6. O movimento das "Diretas Já" (1984).
